# Screenshots and Demonstration Checklist

Capture genuine screenshots from the running application.

## Suggested Screenshots

- [ ] Gateway health endpoint.
- [ ] Backend health endpoint.
- [ ] Gateway Swagger UI.
- [ ] Successful protected API request.
- [ ] Authentication failure.
- [ ] RBAC permission denial.
- [ ] Rate-limit HTTP 429 response.
- [ ] Administrator login.
- [ ] Dashboard overview.
- [ ] Monitoring page.
- [ ] Audit logs page.
- [ ] Clients page.
- [ ] Rate limits page.
- [ ] Security page.
- [ ] Frontend lint and build output.
- [ ] Security test results.

## Demonstration Checklist

- [ ] Start backend, gateway and frontend.
- [ ] Verify service health.
- [ ] Create or use a valid API client.
- [ ] Demonstrate protected API access.
- [ ] Demonstrate authentication failure.
- [ ] Demonstrate RBAC.
- [ ] Demonstrate rate limiting.
- [ ] Log in to the administrator dashboard.
- [ ] Inspect monitoring and audit logs.
- [ ] Log out and verify session invalidation.

Never expose API keys, HMAC secrets, passwords or session cookies in screenshots.
